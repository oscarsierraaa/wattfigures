The wattage is a peak while the heating element runs, not a steady draw — which is why washers and dishwashers are measured per cycle. Energy and cost at $0.18/kWh, the US average.

Like a washing machine, a dishwasher's cost is set by the programme you pick, not by how long the cycle runs, so it is measured per cycle rather than by watts and hours. Almost all of the energy goes into heating water — both the wash water and, on many machines, the hot-air drying at the end. A typical eco cycle uses around 1.0–1.3 kWh, while an intensive hot programme can use half as much again. Dishwashers often get a bad reputation for energy use, but a full machine on an eco setting is usually more efficient than washing the same load by hand under a running hot tap, because it uses less hot water overall. The waste comes from running half-empty loads, using intensive programmes for lightly soiled dishes, and leaving the heated-dry option on when the dishes could air-dry just as well with the door cracked open.

The energy label is the quickest way to gauge a machine, but your own habits decide the real bill. Two identical dishwashers can cost very different amounts to run if one household always uses the intensive programme and the other lives on eco. Running the machine only when it is full, and choosing the longer low-temperature cycle for everyday loads, are the two changes that move the yearly figure most — the calculator above lets you test them against your own price per kWh.

If you came looking for a wattage, a dishwasher draws somewhere between 1,200 and 2,400 W, around 1,800 W on a typical machine — but that number is a peak, not a running cost. It applies only while the heating element is warming the water, which is a few minutes of a cycle that runs for two hours or more. The rest of the time the machine is pumping and draining on a few tens of watts. That is why the figure worth knowing is the 1.1 kWh a typical eco cycle uses from start to finish, and why an hourly figure for a dishwasher describes almost nothing: the same machine would look four times cheaper or dearer depending on which hour you measured.

How to cut dishwasher running costs

  • Only run a full load — a half-empty cycle costs almost the same as a full one.
  • Use the eco programme: it is longer but heats less water, which is where the money goes.
  • Skip the heated-dry option and open the door at the end to let dishes air-dry.
  • Scrape rather than pre-rinse under a hot tap; modern detergents handle the rest.
  • Run it on an off-peak tariff overnight if you have one.

Frequently asked questions

How much does a dishwasher cost to run per cycle?

At about 1.1 kWh for an eco cycle and $0.18/kWh, roughly $0.20 per run. An intensive hot programme can cost noticeably more because it heats more water.

Is a dishwasher cheaper than washing by hand?

A full machine on eco usually is, because it uses less hot water than a running tap. Hand-washing wins only for a very small number of items.

Does the eco programme really save money if it takes longer?

Yes. It runs longer at a lower water temperature, and heating water is what costs money, so total energy is lower despite the extra time.

How many watts does a dishwasher use?

Between 1,200 and 2,400 W while the heating element is on, with about 1,800 W typical. That is the peak draw, not the average — across a whole eco cycle the machine averages far less, which is why energy labels quote kWh per cycle instead of watts. For a modern machine on eco, 1.1 kWh a cycle is the figure to plan with.

How much electricity does a dishwasher use per month?

At five eco cycles a week, about 24 kWh a month — roughly $4.29 at $0.18/kWh. Running it every day takes that to about 33 kWh. Switching from eco to an intensive hot programme raises it by around half again, which is a bigger change than anything else you can do short of running the machine less often.
